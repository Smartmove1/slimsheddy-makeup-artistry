# Slimsheddy Makeup Artistry — Website

A luxury, fully responsive landing page for **Slimsheddy Makeup Artistry**, 
based in Abeokuta, Nigeria.

---

## 📁 Project Structure

```
slimsheddy-makeup/
│
├── index.html                  ← Main website file
│
├── css/
│   ├── style.css               ← All main styles
│   └── responsive.css          ← Media queries & responsive rules
│
├── js/
│   ├── app.js                  ← Core: loader, navbar, slider, counters, FAQ
│   ├── gallery.js              ← Portfolio filter + image modal
│   ├── video.js                ← Video modal system
│   └── whatsapp-booking.js     ← WhatsApp booking form handler
│
├── images/
│   ├── hero/                   ← Hero slider images (4 images)
│   ├── clients/                ← About section photos
│   ├── services/               ← One photo per service card
│   ├── gallery/                ← Portfolio + video thumbnails
│   ├── reviews/                ← Client testimonial photos
│   └── logo/                   ← Logo files
│
├── videos/
│   └── *.mp4                   ← Transformation videos
│
├── assets/
│   └── icons/                  ← Custom icons (optional)
│
└── images/IMAGES-GUIDE.md      ← Full guide for replacing images
```

---

## 🚀 How to Use

1. **Open `index.html`** in any browser — no server needed for basic viewing.
2. **Replace images** — see `images/IMAGES-GUIDE.md` for filenames and sizes.
3. **Add videos** — drop MP4 files into `/videos/` with names: `video-1.mp4`, etc.
4. **Customise text** — edit `index.html` to update any copy, names, or prices.
